# Minecraft Staff Operations

Use this skill for administrator, developer, moderator, builder, support, event, and operations-team management.

## Role contract

For each role document responsibilities, authority boundaries, required access, prohibited conflicts, escalation targets, response expectations, and who can approve exceptional actions.

## Staff lifecycle

1. screen for the role's actual responsibilities rather than prestige;
2. onboard with rules, tools, security expectations, and supervised practice;
3. grant least-privilege access only after it is needed;
4. maintain runbooks and handoff channels;
5. review performance using documented outcomes and conduct;
6. adjust access immediately when responsibilities change;
7. offboard by revoking game permissions, panel/SSH, databases, bots, repositories, secrets, and shared credentials as applicable.

## Operational safeguards

Use two-person review or explicit approval for exceptionally destructive actions where feasible. Keep staff disciplinary matters need-to-know. Record production changes and significant moderation overrides so accountability does not depend on memory.
