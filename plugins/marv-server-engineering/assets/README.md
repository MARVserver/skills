# Public listing assets

Before OpenAI public submission, add/upload an original MARVserver-owned square logo suitable for the plugin listing.

Requirements for this repository:

- use MARVserver-owned branding only;
- do not use the Minecraft logo, Mojang/Microsoft logos, or official Minecraft artwork as the plugin logo;
- keep the public product name `MARV Server Engineering for Minecraft`;
- keep the unofficial-product disclaimer visible in listing materials.

The plugin manifest intentionally omits `logo` and `composerIcon` until an approved publisher-owned asset is supplied.
