# MARV Server Engineering for Minecraft

A skills-only Minecraft server engineering and operations pack from MARVserver.

> **NOT AN OFFICIAL MINECRAFT PRODUCT. NOT APPROVED BY OR ASSOCIATED WITH MOJANG OR MICROSOFT.**

## Install

```bash
codex plugin marketplace add MARVserver/skills && codex plugin add marv-server-engineering@marvserver
```

Start a new Codex thread after installation.

## Components

- `.codex-plugin/plugin.json` — package metadata
- `skills/index/SKILL.md` — router for broad and multi-domain work
- `skills/*/SKILL.md` — 31 specialist skills

No MARVserver-operated backend, account, API key, MCP server, RCON endpoint, hosting panel, or database connection is required to use the skills.

## Scope

The pack covers plugin/mod/content development, architecture/testing, configuration/networking, permissions/security, gameplay/economy, SRE/DevOps, moderation, community/staff/support operations, LiveOps, commerce, analytics, and capacity planning.
