# Minecraft Events and LiveOps

Use this skill for scheduled events, seasonal resets, tournaments, content launches, giveaways, and high-concurrency moments.

## Event plan

Define objective, audience, start/end times and timezone, game rules, capacity assumptions, required plugins/config/content, staff roles, announcement plan, abuse controls, success metrics, and rollback/cancellation conditions.

## Preflight

- rehearse the event on staging or a controlled server;
- validate permissions, commands, scoring/rewards, timers, and persistence;
- verify backups and rollback points;
- estimate peak players and load-sensitive mechanics;
- prepare moderation/support coverage and an incident channel;
- freeze unrelated risky changes close to the event.

## During event

Monitor join success, TPS/MSPT, CPU/memory/network, errors, queue/load, scoring integrity, abuse reports, and support volume. Assign one operational owner for go/no-go decisions.

## Closeout

Verify rewards exactly once, clean temporary permissions/config/tasks, preserve results/evidence, announce outcome, review incidents and capacity, and convert lessons into fixes before repeating the format.
