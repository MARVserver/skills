# Minecraft Player Support

Use this skill for tickets, help channels, restoration requests, account issues, bug reports, and player-facing troubleshooting.

## Intake

Collect only the information required to act: player identity, server/mode, time window, concise symptom, reproduction steps, relevant transaction/order identifiers when applicable, and screenshots/logs that do not expose secrets.

## Triage

Classify the request as how-to, known issue, bug, outage, moderation/appeal, purchase/entitlement, data restoration, security/account concern, or feature request. Route cases with sensitive evidence to restricted channels.

## Resolution rules

- Verify authoritative server records before granting replacement items, currency, ranks, or entitlements.
- Avoid requiring players to reveal passwords, authentication tokens, or unnecessary personal information.
- Use predefined restoration/compensation policy rather than ad-hoc generosity by individual staff.
- Link duplicate incidents to one underlying problem.
- Escalate reproducible bugs with version, steps, expected/actual behavior, and evidence.
- Record the final action so another staff member can understand what changed.

Support quality should be measured by correctness, consistency, recurrence, and player effort, not only by ticket closure speed.
