# Install

## Fastest install

Paste this into a shell with the Codex CLI installed:

```bash
codex plugin marketplace add MARVserver/skills && codex plugin add marv-server-engineering@marvserver
```

Then start a new Codex thread.

## Already added the marketplace?

You only need:

```bash
codex plugin add marv-server-engineering@marvserver
```

## Verify

```bash
codex plugin list
```

Look for:

```text
marv-server-engineering@marvserver
```

No MARVserver account, API key, MCP server, RCON endpoint, or other external service is required to use the skill pack itself.
