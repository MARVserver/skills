# Support — MARV Server Engineering for Minecraft

For support with the Plugin, use one of these channels:

- Public bugs, documentation problems, compatibility reports, and feature requests: https://github.com/MARVserver/skills/issues
- Private matters that should not be posted publicly: marvsystem@gmail.com
- Publisher website: https://marvgame.com

Before opening a public issue, remove credentials, access tokens, private server addresses, player personal data, private moderation evidence, database dumps, and other confidential material.

When reporting a technical problem, include the smallest useful reproducible context: the affected skill, Minecraft/server implementation and version when relevant, Java/runtime version, expected behavior, observed behavior, and sanitized logs or error messages.
