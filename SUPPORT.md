# Support

Use the channel that matches your request so it can be handled efficiently.

## Bug reports

Open a GitHub issue using the **Bug report** form when an existing skill, installer, validator, or repository workflow behaves incorrectly.

Before reporting, check the latest `main` branch and include enough environment and reproduction detail for someone else to verify the problem.

## Questions and troubleshooting

Use GitHub Discussions under **Q&A** for usage questions, implementation guidance, troubleshooting, and requests for clarification that are not confirmed repository bugs.

## Ideas and new skills

Use GitHub Discussions under **Ideas** for new skill proposals, major scope changes, workflow improvements, or design proposals. For substantial work, discussion before implementation helps avoid duplicated or incompatible approaches.

## Security

Do not use public issues or discussions for security vulnerabilities. Follow `SECURITY.md`.

## Scope

This repository provides the skill pack itself. It does not provide a hosted Minecraft server, MARVserver account, managed operations service, RCON endpoint, database, or private infrastructure access.

Questions about third-party Minecraft software may require verification against that project's current documentation and supported versions.
