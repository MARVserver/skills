# Privacy Policy — MARV Server Engineering for Minecraft

Effective date: August 15, 2026

This Privacy Policy describes the data practices of **MARV Server Engineering for Minecraft** (the "Plugin"), published by MARVserver.

> **NOT AN OFFICIAL MINECRAFT PRODUCT. NOT APPROVED BY OR ASSOCIATED WITH MOJANG OR MICROSOFT.**

## 1. Plugin architecture

Version 0.2.0 of the Plugin is a **skills-only OpenAI plugin**. It contains reusable workflow instructions and does not operate a MARVserver-hosted MCP server, API, RCON endpoint, database, analytics service, or other backend for Plugin use.

As a result, the Plugin itself does not transmit user prompts, files, ChatGPT conversations, server credentials, player information, or other task content to MARVserver.

## 2. Information MARVserver receives through Plugin use

MARVserver does **not** receive Plugin-use content merely because a person installs or invokes this skills-only Plugin in ChatGPT or Codex.

MARVserver may receive information only when a user independently chooses to interact with MARVserver, for example by:

- opening an issue or pull request in the public GitHub repository;
- emailing the publisher/support address;
- using a separate MARVserver website or service.

In those cases, MARVserver receives the information the user voluntarily provides, together with ordinary metadata produced by the service used to contact MARVserver.

## 3. OpenAI and third-party services

Use of ChatGPT, Codex, the Plugin Directory, or other OpenAI services is governed by OpenAI's own terms and privacy practices.

The skills may recommend or help a user work with external systems such as GitHub, Discord, hosting panels, monitoring systems, databases, object storage, or server administration tools. Version 0.2.0 does not bundle or automatically connect those systems. If a user separately enables or uses a third-party service or OpenAI app, that service processes data under its own terms, permissions, and privacy policy.

The Plugin does not grant access to an external system and does not override the user's existing authorization in that system.

## 4. Telemetry, advertising, and sale of personal data

Version 0.2.0 contains no MARVserver-operated telemetry or advertising component for Plugin usage.

MARVserver does not sell personal data obtained through Plugin support interactions.

## 5. Support and repository interactions

Public GitHub issues, pull requests, comments, and other repository activity may be visible publicly after submission. Users should not post credentials, private server addresses, access tokens, player personal data, moderation evidence containing sensitive information, or other confidential material in public repository content.

For information that should not be public, contact MARVserver using the publisher email listed in the Plugin manifest.

## 6. Retention

Because version 0.2.0 does not operate a MARVserver backend for Plugin use, MARVserver does not maintain a Plugin-specific store of prompts, files, conversations, or execution data.

Information voluntarily submitted to MARVserver through support email, GitHub, or another separate MARVserver service may be retained as reasonably necessary to respond to the request, maintain security and operational records, resolve disputes, or comply with applicable obligations. Data held by third-party platforms is also subject to those platforms' retention controls and policies.

## 7. Security

The Plugin is designed to avoid embedding production secrets or requiring MARVserver credentials. Users should keep secrets out of prompts, public issues, commits, and logs unless the relevant system and workflow are specifically intended to handle them securely.

The skills emphasize least privilege, source-system authorization, backups, rollback, and verification for potentially risky operations.

## 8. Children and Minecraft accounts

The Plugin is a developer and server-operations workflow package. It does not independently create or manage Microsoft, Minecraft, Discord, or OpenAI accounts. Account eligibility and parental/guardian requirements are governed by the relevant service providers and applicable rules.

## 9. Changes to this policy

If a future Plugin version adds a MARVserver-operated app, MCP server, telemetry service, authentication system, or other backend that changes data flows, MARVserver will update this policy and the Plugin listing before representing that version as covered by this policy.

Material changes will be reflected by updating this document and its effective date.
