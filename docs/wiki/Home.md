## Project principles

The skill pack is designed around:

- version-aware Minecraft engineering guidance;
- evidence-first debugging;
- least-privilege operations;
- backup and rollback before risky changes;
- explicit post-change verification;
- minimal exposure of credentials, infrastructure secrets, and player data.

## Scope

This repository distributes Codex skills. It does not provide hosted Minecraft infrastructure, private MARVserver systems, managed server access, an RCON endpoint, or a backend service.
